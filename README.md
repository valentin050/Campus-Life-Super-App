# Campus Life Super App

A simple website for checking Lynchburg weather, looking up sample dining hours, and finding campus locations.

- Home shows weather from Open-Meteo and alerts from the National Weather Service.
- Dining has a weekday and weekend dropdown.
- Campus Map shows the campus area on OpenStreetMap.

The site uses HTML, CSS, Bootstrap, and JavaScript. Open index.html to run it locally. For deployment, set GitHub Pages to deploy from the main branch and the root folder.

A future update can add verified dining hours and markers for each campus building.
